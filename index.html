Current web tools

Useful before, during, and after every war.

The dashboard is functional today, but remains an alpha while shared clan accounts and server synchronization are being built.

Village Tracker

Import a village JSON snapshot, inspect Home Village and Builder Base levels, active timers, progress categories, and changes between snapshots.

Upgrade Planner

Build a queue, assign builder or laboratory lanes, estimate start and completion dates, and account for manual time and cost discounts.

War Room

Create wars, select the roster, assign both attacks, record stars and destruction, and keep an automatically ordered cleanup board.

CWL Bonus Tracker

Track seven daily scores, average destruction, ranking, bonus positions, and archive completed seasons as read-only records.

Clan Messages

Generate assignments, cleanup lists, and reminders formatted into messages that respect the in-game character limit.

Local Backups

Export and restore villages, plans, wars, members, and CWL seasons while the cloud version is still under development.
