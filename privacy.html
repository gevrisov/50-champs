Privacy notice

Current alpha: village snapshots, upgrade plans, clan members, war records, and CWL seasons are stored in your browser on your device. This version has no user accounts and no 50 Champs cloud database.

Data handled locally

The application reads the village JSON you choose to import and stores the resulting data in browser local storage. Downloaded backup files are created only when you request them.

External network request

The application may request a pinned public game-data catalog from jsDelivr to calculate category progress. Previously calculated summaries may be cached locally.

What is not collected

This alpha does not request a Supercell ID password, payment data, precise location, contacts, camera access, or microphone access.

Deleting local data

You can clear the application data through the app controls or through your browser's site-storage settings. Download a backup first if you need to preserve the information.
